# Projeto-da-Atividade-Extensionista-da-Faculdade-Uninter
StudyTrack — aplicação web desenvolvida para a Atividade Extensionista de Tecnologia Aplicada à Inclusão Digital da UNINTER. Permite organizar estudos, acompanhar metas, utilizar o Pomodoro e participar de grupos, com Python, Streamlit e Supabase.
